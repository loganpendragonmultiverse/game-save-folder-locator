# Changelog

## 1.2.0 - 2026-10-16

- Added report-only catalog comparison by stable record ID with complete before/after evidence.
- Highlighted potential conflicting defaults without selecting a preferred path.

## 1.1.0 - 2026-09-07

- Ship nine sourced save-folder records for Factorio, Stardew Valley and OpenTTD, with explicit path inspection and confidence labels.

- Added a versioned, source-aware game-save path catalog format.
- Added case-insensitive game search and operating-system, platform, and path-type filters.
- Added record validation, Markdown and JSON reports, and contribution guidance.
